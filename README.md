# Borozdov Porcelain

A theme from the Borozdov collection. Two faces — light **Showroom**, a Scandinavian
gallery on porcelain, and dark **Alcove**, the same gallery lit for the evening. White silk,
square corners, ghost pill buttons, hairline rules and one ultramarine plane for what you
act on.

![Borozdov Porcelain in light mode](https://raw.githubusercontent.com/borozdov-obsidian-themes/porcelain/main/screenshots/light.png)

![Borozdov Porcelain in dark mode](https://raw.githubusercontent.com/borozdov-obsidian-themes/porcelain/main/screenshots/dark.png)

## Principles

- **A gallery wall.** The page is porcelain white, the side panels bone; cards are
  invisible — bone panels with square corners and no edge — and nothing casts a shadow.
- **One plane, never a text colour.** A saturated ultramarine fills the main button, a
  checked task, a toggle, the open file and the selection. Links stay ink with an
  underline and let the plane show through on hover.
- **Tracking that inverts.** One voice, the platform's own sans: tight on the title and
  headings, open on micro-labels. Tags, table headers, callout titles and property names
  are small tracked capitals, like captions on a wall.
- **Pills against squares.** Every container is square; buttons are ghost pills with a
  hairline rim that invert on hover. Text fields are a single underline.

## Features

- Light and dark modes, following Settings → Appearance → Base color scheme
- Callouts as bone panels captioned in small capitals in the type's colour
- Tags as flat ink blocks with white captions
- Tables with hairline rules and square corners
- Quiet editing: no focus ring around the note, its title or form fields while you type;
  property names read as labels, not boxed fields
- Text colours meet WCAG contrast on both faces
- The phone layout keeps the same colours and shapes
- No embedded fonts, so the theme stays around 12 KB
- No `!important`: every rule can be overridden with a CSS snippet

## Installation

**From the community directory:** Settings → Appearance → Themes → Manage, search for
**Borozdov Porcelain**, then **Install and use**.

**By hand:** download `manifest.json` and `theme.css` from the
[latest release](https://github.com/borozdov-obsidian-themes/porcelain/releases/latest) into
`<vault>/.obsidian/themes/Borozdov Porcelain/`, then choose Borozdov Porcelain under
Settings → Appearance → Themes.
